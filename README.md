# One Line, Zero Use — The Useless Superpower Sprint

Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68): one original line, at most 200 characters, describing a hilariously useless superpower.

## The line

> I can teleport anywhere in the world, as long as it's this room.

## How it works

`main.py` (Python 3, standard library only, no network) writes that exact
line to `/output/entry.txt`. The output is deterministic: every run produces
byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
